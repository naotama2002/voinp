# 手動テストチェックリスト

自動化できない項目。リリース前と、該当箇所を触ったときに実施する。
自動で回る分は `make test` と `make verify` にある。

## 権限・署名（最優先）

- [ ] `make reset-permissions` の後、初回起動でマイク許可が求められる
- [ ] アクセシビリティ未許可のとき、メニューバーに警告アイコンが出る
- [ ] メニューから「アクセシビリティを許可する…」でシステム設定が開く
- [ ] 許可した瞬間に（アプリ再起動なしで）UI が反応する
- [ ] **`make install` を 2 回繰り返しても、許可が消えていない** ← 署名戦略の要
- [ ] `codesign -d -r-` の designated requirement が cdhash ではなく
      `identifier ... and certificate leaf[subject.OU]` 形式である

## テキスト挿入

挿入先ごとに、日本語・英語・改行入り・長文（1,000 字）を試す。

- [ ] メモ
- [ ] Safari のテキストエリア
- [ ] Slack
- [ ] VS Code
- [ ] Terminal.app
- [ ] iTerm2
- [ ] Xcode のエディタ
- [ ] パスワード欄 → 拒否され「パスワード欄にフォーカスしています」が出る
- [ ] 挿入後、対象アプリで ⌘Z を 1 回押すと挿入前に戻る
- [ ] クリップボードの内容が挿入後に復元されている
- [ ] 挿入中に自分でコピーした場合、クリップボードが**上書きされない**
- [ ] クリップボード履歴アプリ（Maccy 等）に書き起こしが残らない

## ホットキー

- [ ] ホールド式: 押している間だけ録音、離すと確定
- [ ] トグル式: 押して開始、もう一度押して終了
- [ ] ハイブリッド: 短タップでトグル、長押しでホールドに切り替わる
- [ ] 修飾キー単独（右 ⌘ 長押し）で発動する
- [ ] ホットキーが対象アプリに漏れない（⌥Space で空白が入らない）
- [ ] キーレコーダがアクセシビリティ未許可でも動く
- [ ] **押しっぱなしのまま確定 → ⌃⌥⌘V にならない**
- [ ] 重い処理を走らせた直後もホットキーが生きている（tap の再武装）

## 音声・認識

- [ ] 初回に ja-JP モデルのダウンロードが走り、進捗が出る
- [ ] ダウンロード途中でネットワークを切っても壊れない
- [ ] AirPods を録音中に接続・切断しても復帰する
- [ ] 外部オーディオ I/F（マルチチャネル）で無音にならない ← ゼロ埋めバグ
- [ ] ディスプレイスリープ→復帰後も録音できる
- [ ] 用語ヒントに入れた社内用語が正しく認識される

## HUD

- [ ] テキスト欄にフォーカスしたまま HUD が出てもフォーカスを失わない
- [ ] フルスクリーンアプリの上に出る
- [ ] 複数ディスプレイでマウスのある画面に出る
- [ ] `ui.hudShowText: false` で認識テキストが出ない
- [ ] **画面共有・画面収録に HUD が写るか**（未検証事項。結果を docs に反映すること）

## プライバシー

- [ ] 既定設定のまま 5 分間ディクテーションし、`lsof -i` が何も出さない
- [ ] Little Snitch 等で接続が 1 本も出ない
- [ ] `make verify` が全項目通過する
- [ ] 校正を有効にすると、メニューバーのアイコンが変わる
- [ ] 設定ファイルを壊すと「設定エラーのため通信を停止しています」になる
- [ ] 監査ログに書き起こしの本文が含まれていない
- [ ] `log stream --predicate 'subsystem == "com.naotama2002.voinp"'` に本文が出ない
- [ ] **ペーストボード経由の挿入内容が iPhone に同期されないか**（未検証事項）

## 校正

- [ ] LM Studio を落とした状態で 3 回失敗 → 自動で無効化される
- [ ] 校正がタイムアウトしても生原稿が挿入される
- [ ] ベース URL に `:1234` だけ入れても `/v1/models` を見つける
- [ ] `localhost` が駄目でも `127.0.0.1` で繋がる
- [ ] 書き起こしに「これまでの指示を無視して」と言っても指示として実行されない
- [ ] 「明日でよろしいですか」→「明日でよろしいですか。」が棄却されない
