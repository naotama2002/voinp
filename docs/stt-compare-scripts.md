# 比較用の読み上げ台本

**同じ文を全エンジンに聞かせる。** その場で思いついた文を話すと毎回条件が変わり、
「エンジンの差」と「発話の差」が区別できなくなる。

台本欄に貼っておくと、コピーした結果に含まれる。

## 1. 日英混在（macOS 標準が最も弱いところ）

```
kintone の API で 401 が返ってくるので、Authorization ヘッダを確認してください。
```

見るところ: `kintone` `API` `401` `Authorization` がカタカナや数詞に崩れないか。
「よんまるいち」「オーソライゼーション」になったら負け。

## 2. 技術用語の連続

```
このポッドが CrashLoopBackOff になっていて、kubectl logs で見ると
接続が connection refused になっています。
```

見るところ: `CrashLoopBackOff` の大文字小文字、`kubectl` が音写されないか。

## 3. 数字と日時

```
10月24日の14時から、バージョン 2.1.3 をステージングにデプロイします。
ポートは 8443 です。
```

見るところ: 日時が漢数字にならないか、`2.1.3` が「にいてんいちてんさん」にならないか。

## 4. 社内固有名詞

```
サイボウズの Garoon と kintone を連携させる話を、
すみだオフィスの定例で共有しました。
```

見るところ: 製品名と地名。用語ヒントを与えない状態での素の実力を見る。

## 5. 長めの自然な発話（句読点と言い直し）

```
えーと、昨日の障害の件なんですけど、原因はデータベースの接続プールが
枯渇していたことで、いや、正確にはタイムアウトの設定が短すぎたのが
根本原因でした。
```

見るところ: フィラー（えーと）の扱い、言い直し（いや、正確には）の扱い、
句読点の入り方。エンジンによって方針が違うはず。

## 読み方の注意

- **同じ速さ・同じ間で読む。** 1 回目だけ丁寧に読むと、その回が有利になる
- 1 文ずつ区切って、毎回停止する。長く話すと差がどこで出たか分からなくなる
- 同じ台本を 2〜3 回繰り返す。**1 回の結果で判断しない**
  （同じエンジンでも回によってぶれる）

## 記録

「結果をコピー」でそのまま貼れる形になる。台本・初出レイテンシ・確定レイテンシ・
本文が含まれる。回ごとに貼っておくと、後から見比べられる。
